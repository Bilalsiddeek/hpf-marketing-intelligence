# Platforms Watchlist

**Primary sources** for algorithm, feature, ad-product and policy changes. Always prefer these over "every Meta update this month" aggregator posts, which are for discovery only.

**Check daily** = the agent `WebFetch`es this URL on every run. All other entries are searched when discovery surfaces them.
**Access** is how the agent can actually read it: `Fetch` (WebFetch works) · `Browser` (needs the built-in browser; JS-rendered) · `Search` (reach via WebSearch results).
