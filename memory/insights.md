# HPF Insights Memory

HPF's evolving, **evidence-backed point of view**. Each insight is something that has repeatedly held up across research and should change what HPF says, sells, recommends or makes.

**Promotion rule** (from the skill): an insight is added only when it's backed by a trend that's `Strengthening` or `Established` in `trends.md`, **or** by strong primary data, **and** it changes HPF's behaviour. A single article is never enough.

**Update rule:** never delete. When evidence shifts, update *Confidence* and add to the *Evidence log*. If an insight is disproven, set *Status: Retired* and give the reason.

**Confidence scale:** `Low` (directional, 1 strong source) · `Medium` (2–3 independent sources or 1 trend) · `High` (Established trend + primary data).
